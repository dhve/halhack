# HALHack

The landing page for the human–agent loop hackathon.

Live site: https://dhve.github.io/halhack/

The site is static HTML, CSS, and JavaScript. GitHub Pages publishes the repository root from the main branch. No build step or API keys are needed.

## Update the site

Edit `index.html`, `styles.css`, or `app.js`, then push to `main`. The signup links open the published HALHack Google interest form.

For local preview, run `python3 -m http.server 4173` and open `http://localhost:4173/`.

## Files

- `index.html` contains the page content and links.
- `styles.css` contains responsive styles.
- `app.js` controls mobile navigation.
- `assets/` contains the favicon and the supplied NANDA Town replay image.

The NANDA Town image shows an older replay. Event dates, detailed rules, prizes, and partner commitments are not announced on the page.
